🛡️ Privacy & Transparency

Privacy Policy

Last updated: March 2026

Summary: DevPulse is engineered with a strict Privacy-First philosophy. All hardware telemetry, diagnostic test results, sensor readings, and system metrics are processed 100% locally on your device. No data is collected, stored remotely, or transmitted to any external server.

1. Information We Collect (Or Don't Collect)

DevPulse does not collect, store, transmit, or share any personal data, identifiers, location tracking data, or usage metrics with third parties.

  • No Personal Identifiers: We do not log names, email addresses, phone numbers, or device serial numbers.
  • No External Telemetry: System metrics (CPU frequencies, RAM usage, battery health, thermal zone readings) stay entirely in device RAM during runtime.
  • No Analytics SDKs: DevPulse does not integrate Firebase Analytics, Google Analytics, Mixpanel, or any third-party tracking scripts.
  • No Advertising SDKs: DevPulse contains zero advertisements and zero ad-tracking frameworks.

2. Local Storage & App Permissions

DevPulse requires specific system permissions solely to read hardware state and execute diagnostic tests on-device:

  • Hardware Diagnostic Tests: Hardware test results (e.g. Passed/Failed status) are saved strictly locally using Android SharedPreferences and DataStore Preferences.
  • Camera & Microphone Diagnostics: Access is used strictly during interactive test execution (e.g. camera spec inspection & microphone sound meter) and is never recorded or transmitted.
  • Connectivity & SIM State: Network capabilities, Wi-Fi 6E checks, and SIM carrier names are queried via standard Android APIs locally.

3. Third-Party Services

DevPulse is a fully standalone native application. The app does not communicate with external API endpoints, except when checking for app updates directly via the public GitHub Releases API (api.github.com).
